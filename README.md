# Custom-Mechanical-Hinge
A custom mechanical hinge designed using Onshape CAD. The model consists of two main parts (Part 1 &amp; Part 2) that interlock and allow rotation, simulating a basic hinge mechanism. Includes 5-inch inward screw holes for mounting, and hollow black-filled pivot holes for pin insertion or bolt fastening.
# Custom Mechanical Hinge – Onshape CAD Project

## Features

- Two-part hinge design with aligned pivot holes.
- 5-inch inward screw clearance for secure mounting.
- Hollow circular pivot zones (black-filled) to accommodate hinge pins or bolts.
- Designed with manufacturing precision and functional movement in mind.


## Tools Used

- [Onshape](https://cad.onshape.com/)
